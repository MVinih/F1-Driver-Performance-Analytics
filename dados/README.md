# Dados

A base inicial é criada pelos arquivos SQL em `sql/`, a partir de um exemplo pequeno documentado pela Jolpica.

Não inclua aqui backups completos (.bak), credenciais ou grandes datasets. Quando houver processo de importação, documente a origem, os filtros e como reproduzi-lo.

API: https://github.com/jolpica/jolpica-f1/blob/main/docs/README.md
